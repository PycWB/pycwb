Extend a Worked Example
=======================

Modify the shared synthetic example, then inspect what changed. These lessons
use a local generator, a frequency-band comparison, a report workflow, and a
small resource-and-restart experiment.

To apply these workflows to your project, use :doc:`injection_infrastructure`,
:doc:`postproduction_workflow` and :doc:`workflow_execution`. Cluster submission
and streaming setup are covered in :doc:`run_on_clusters` and
:doc:`online_search`.

For the Python stages behind the examples, see :doc:`tutorial_search` and
:doc:`tutorial_injection` under :doc:`core_concepts`.
