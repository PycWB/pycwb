# Getting help

PycWB is hosted on [GitHub](https://github.com/PycWB/pycwb) and [LIGO GitLab](https://git.ligo.org/yumeng.xu/pycwb), with the repositories mirrored. Contributors outside LVK can report issues and submit pull requests on GitHub without an LVK account.

Use [GitHub issues](https://github.com/PycWB/pycwb/issues) or [GitLab issues](https://git.ligo.org/yumeng.xu/pycwb/-/issues) for reproducible bugs and feature requests. If you cannot access either tracker, contact the package maintainer at yumeng.xu@ligo.org. LIGO Slack membership is not required to request help.

Include the PycWB version/commit, platform, Python version, exact command, minimal configuration, relevant error log and `python -m pip list` output. State whether the CLI example in `examples/demo/` works. Remove credentials and private data before sharing diagnostics publicly.

For suspected security problems, email the package contact privately. The project does not currently advertise a response-time or long-term-support commitment.

See the [troubleshooting guide](docs/source/troubleshooting.rst), [community guide](docs/source/support.rst), and [contribution instructions](CONTRIBUTING.md).
