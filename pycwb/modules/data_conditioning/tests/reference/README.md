# Regression-cap oracle

`regression_cap_oracle.npz` and `.json` were generated by the separately installed cWB 6.4.6.9 (`e03cf7f`) using `runs/regression_cap/oracle.py` in the enclosing analysis workspace. They contain explicit witness quadratures, normalization, fitted filters and release noise predictions for 24 controlled cases. Tests do not require ROOT. The witness cap is 5 times the selected energy order statistic; fraction 1 retains old uncapped behavior. The fixture checks filter application, not only an independently reimplemented threshold.

# Regression witness oracle

`regression_witness_oracle.npz` and `.json` capture cWB 6.4.8.0 commit
`4dddd134f2cf47768ad22054e95beec888d0ae9c`, H1 MDC short0 job 109, at 60 Hz.
The target is the original transform; the witness is transformed after mean
subtraction. Arrays include both quadratures, separate norms, the cWB matrix,
cross vector, eigenvalues and filter taps. The 95% trim keeps different samples
when the target is incorrectly substituted for the witness. Tests verify
statistics and noise reconstructed from the captured cWB filter; ROOT and frame
files are not required at test time.

Capture source in the analysis workspace:
`runs/picasso_mdc_diagnosis_20260929/regression_probe109details.C` and
`regression_probe109witness.C`. The accompanying JSON records analysis rate,
filter length, trim fraction, edge samples and solver settings.
